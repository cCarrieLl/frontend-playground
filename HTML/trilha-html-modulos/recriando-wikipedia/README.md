# 📚 Clone da Wikipédia

Este projeto foi desenvolvido como parte de um desafio proposto pela plataforma de ensino DIO (Digital Innovation One). O principal objetivo foi recriar uma página inspirada na Wikipédia, colocando em prática conceitos fundamentais de HTML5, com foco na estruturação semântica do conteúdo e na acessibilidade.

---

## 🎯 Objetivos do Projeto

- Praticar a estruturação correta de páginas utilizando HTML5.
- Aplicar elementos semânticos para melhorar a organização do conteúdo.
- Desenvolver uma interface mais acessível para pessoas que utilizam leitores de tela.
- Compreender a importância da acessibilidade no desenvolvimento web.
- Reforçar boas práticas de desenvolvimento front-end.

---

## ♿ Acessibilidade

Durante o desenvolvimento, procurei aplicar conceitos voltados à acessibilidade, buscando criar uma experiência mais inclusiva para usuários com deficiência visual. Esse foi um dos pontos mais importantes do projeto, pois me ajudou a entender como pequenas decisões na estrutura do código podem impactar diretamente a experiência de diferentes usuários.
