# Estudos de Front-end

Durante meus estudos aprofundados na área de Back-end, percebi a necessidade de aprender novas tecnologias para me tornar um programador mais completo.

Com isso em mente, comecei minha jornada no Front-end, iniciando pelos conceitos fundamentais de HTML, JavaScript e CSS.

## Objetivo

Este repositório tem como foco:
- prática;
- exercícios;
- testes;
- aprendizado contínuo.

Os conteúdos presentes aqui fazem parte da minha evolução nos estudos e servem como base para projetos mais completos no futuro.

## O que estou utilizando

- Plataforma DIO
- YouTube
- Curso do Gustavo Guanabara

## Observações

Neste momento, o foco não é criar projetos extremamente elaborados, mas sim desenvolver lógica, estruturação e entendimento das tecnologias Front-end.

Projetos mais completos e caprichados serão desenvolvidos conforme minha evolução nos estudos.
